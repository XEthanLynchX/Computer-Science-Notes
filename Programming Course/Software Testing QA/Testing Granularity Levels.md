## Functional Testing vs Non-Functional Testing
**Functional testing** - The testing of the functionality itself. This is making sure that inputs are getting the expected outputs of the program. 

**Non-functional testing** - The testing of things such as reliability, maintainability, usability, etc 

## Acceptance testing 
**Acceptance testing** - The validation of the software against the customer. Making sure the system does what the customer wants/needs it to do 

## Regression Testing 
**Regression testing** - This when a developer makes changes to existing code and after these tests  are in place to make sure it still functions as expected
